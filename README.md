## Projects

### AI Cyber Defense
**[Balaji-india/Ai-Cyber-Defense](https://github.com/Balaji-india/Ai-Cyber-Defense)**

A live cyber-range that pits a learning attacker against a fusion-based defender on real network traffic, rather than replaying a static labeled dataset.

**Key Features**
- Real-time packet capture on the loopback interface using Scapy, with genuine TCP port scans and connection floods fired at localhost
- Detection verdicts fused from a Random Forest classifier (trained on the UNSW-NB15 dataset) and a local LLM's natural-language reasoning
- An adaptive attacker agent that uses a bandit algorithm to change strategy based on what gets blocked
- A Markov-based predictor that forecasts the attacker's next likely move
- Honeypot quarantine for repeat offenders, and explicit scoping of what the sensor can and cannot see (network-visible vs. host-local attacks)

**Results:** 90.14% Random Forest accuracy on live 7-feature flows, with 100% precision on network-visible attacks in testing.

### Agentic Code Auditor
**[Balaji-india/Agentic-Code-Auditor](https://github.com/Balaji-india/Agentic-Code-Auditor)**

An agentic system for auditing codebases and documents: upload an archive or folder (code, PDFs, DOCX, Markdown), and query it through an LLM that retrieves context lazily instead of stuffing an entire repository into the prompt.

**Key Features**
- Sandboxed archive extraction (ZIP/TAR/RAR/7z) with zip-bomb, size, and path-traversal checks before anything is unpacked
- Tree-sitter based code indexing and format-aware document extraction, with content-addressed caching for fast re-runs
- Agentic retrieval loop that pulls context on demand via function-calling, rather than a single large context dump
- Real compiler diagnostics (gcc, javac, go vet, rustc, tsc, and more) executed per-check inside a locked-down, network-isolated Docker container
- Flask-based chat interface backed by persistent DuckDB/SQLite indexes
